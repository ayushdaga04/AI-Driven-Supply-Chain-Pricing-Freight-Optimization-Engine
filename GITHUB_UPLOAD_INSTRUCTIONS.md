# GitHub Upload Instructions

## Repository name

`arv-supply-chain-pricing-intelligence`

## Upload without Terminal

1. On GitHub, select **New repository** and use the repository name above.
2. Keep the repository public if you want recruiters to view it. Do not add a new README; it is already included here.
3. Open this local folder, select everything inside it, and drag the files into GitHub's **uploading an existing file** screen.
4. Commit the upload to the `main` branch.
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/docs`, then save.

The live demo will appear at `https://YOUR-USERNAME.github.io/arv-supply-chain-pricing-intelligence/` after GitHub finishes deploying it.
